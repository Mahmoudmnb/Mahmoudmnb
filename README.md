## 🚀 Featured Projects

### 🎙️ Quran Recitation Analysis

Audio AI research project for **phoneme recognition, phoneme boundary detection, duration estimation, and selected Tajweed-related analysis** using Wav2Vec2, Conformer, CTC, and custom Quran-aware phoneme representations.

[View Repository](https://github.com/Mahmoudmnb/quran-recitation-analysis)

---

### 👁️ Arabic Manuscript OCR

Image-to-text system for recognizing **Arabic handwritten manuscripts** using image feature extraction and a Transformer decoder.

The project explores traditional computer vision preprocessing and deep-learning-based visual recognition, including CNN feature extraction, MobileNet, EfficientNet, and attention-based decoding.

[View Repository](https://github.com/Mahmoudmnb/arabic-manuscript-ocr)

---

### 🛒 Flutter E-Commerce Shop

Open-source Flutter e-commerce application featuring authentication, product browsing, cart, wishlist, orders, checkout, reviews, local caching, and Appwrite backend integration.

[View Repository](https://github.com/Mahmoudmnb/flutter-ecommerce-shop)

---

### 🧠 Neural Networks from Scratch in Dart

Educational implementation of neural networks directly in Dart, including:

- Multilayer Perceptron
- Elman recurrent network
- Manual forward propagation
- Backpropagation
- Weight updates
- Dataset preprocessing
- Model persistence

[View Repository](https://github.com/Mahmoudmnb/neural-networks-from-scratch-dart)

---

### 🧩 Prolog Sudoku Generator & Solver

Sudoku generator and logical solver implemented in Prolog with candidate elimination, uniqueness checks, pair strategies, and puzzle generation.

[View Repository](https://github.com/Mahmoudmnb/prolog-sudoku-generator-solver)
